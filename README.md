# Falling Sand Simulator

A command-line falling sand simulator based on "cellular automaton" like ruleset.
The sand grains appear as dull-yellowish/light-brownish squares while the tiny and dim dots are empty spaces.
The sand falls down and tries to occupies the space both diagonally down left and down right to it.

## Placing Grains

There is a purple circle in the grid as well, which is the pointer.
Move the pointer with your arrow-keys (it can also wrap around edges).
Press \[SPACE\] to place a grain of sand on the current pointer position, if there isn't already one.
However if there already is a grain there, this will delete that grain from there.
